About

Evidence first, then ship.

I'm Asma, an applied AI engineer with four-plus years of building LLM systems that people can trust: retrieval-grounded assistants, tool-using agents, and the evaluation, deployment and monitoring that surround them.

Experience

Where I've built.

Applied AI Engineer

Teledyne Technologies IncJanuary 2025 – Present

At Teledyne I build production RAG pipelines over engineering manuals, product specifications and test records, using Docling and Unstructured for parsing, hybrid BM25 plus dense search with re-ranking, and incremental ingestion to keep indexes current. I designed and deployed agentic systems with LangGraph and MCP servers so engineers can query documentation and internal tools in natural language, with human approval for sensitive actions. An automated evaluation harness (RAGAS, DeepEval, Promptfoo, LLM-as-judge, trajectory and tool-use checks) runs in CI and blocks releases that regress answer quality against a curated golden set. I harden these applications for controlled-data environments with PII masking, prompt-injection defenses mapped to the OWASP LLM Top 10, NeMo Guardrails, Llama Guard and role-based retrieval access, and I serve and tune open-weight models (Llama, Qwen, Mistral) with vLLM on Kubernetes through KServe, fine-tuning task-specific models with LoRA and PEFT. I also implemented model routing, caching, rate limiting and fallbacks with per-request token and cost tracking, instrumented everything with OpenTelemetry, Langfuse, Prometheus and Grafana, and exposed agents and RAG services as secured REST and MCP endpoints with FastAPI, Pydantic and Keycloak/OIDC, deployed on Kubernetes.

MLOps / ML Platform Engineer

Creative Newtech LtdAugust 2020 – August 2023

At Creative Newtech I built and operated an internal ML platform on Kubernetes with MLflow tracking and registry, Kubeflow Pipelines and Airflow, giving data scientists a standard path from notebook to production. I productionized forecasting and recommendation models with scikit-learn and XGBoost, served through FastAPI and KServe to the company's B2B ordering platform, and automated model CI/CD with Docker, Helm, GitHub Actions and Jenkins, including release gates, baseline validation, and canary and shadow rollouts. I built Spark and Kafka data pipelines for sales, inventory and catalog data and introduced a feature store so training and serving used the same features. Model monitoring with drift detection (PSI and KS tests), Prometheus and Grafana triggered automated retraining, infrastructure was provisioned as code with Terraform on AWS (SageMaker, EKS, S3) with compute cost controlled through autoscaling and right-sizing, and inference was optimized with batching, caching and ONNX Runtime. I wrote runbooks so operations teams could support models without engineering escalation.
